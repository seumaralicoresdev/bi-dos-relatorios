# Temas visuais Power BI — rascunhos

Os quatro JSON são paletas independentes para comparar no Power BI Desktop; dois usam fundo escuro. As três imagens PNG são opções de fundo 16:9. Os temas não alteram o modelo nem as consultas, e as imagens não estão embutidas no JSON.

Combinações sugeridas: `fundo_azul_noturno.png` com `azul_meia_noite.json`; `fundo_claro_minimalista.png` com `azul_executivo.json` (ou `verde_energia.json` para uma paleta verde); `fundo_grafite_esmeralda.png` com `grafite_noturno.json`.

Para importar um JSON: **Exibição → Temas → Procurar temas**. Para testar uma imagem, selecione a página do relatório, abra **Formatar página → Tela de fundo da tela (Canvas background)** ou **Papel de parede (Wallpaper)** e escolha o PNG. Os nomes dos controles podem variar um pouco conforme a versão do Power BI Desktop.

Teste em uma cópia do PBIX. Uma paleta escura pode exigir ajustes nas cores de visuais e rótulos definidos manualmente. O JSON foi validado quanto à sintaxe; a importação não foi executada no Power BI Desktop nesta sessão.
